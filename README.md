# THE GX GROUP — thegxgroup.com

Build | Launch | Scale.

- `src/` — React + TypeScript + Tailwind source (Vite)
- `docs/` — the built, pre-rendered site served by GitHub Pages (branch `main`, folder `/docs`)
- `supabase/` — database schema (forms + admin dashboard run on Supabase)

Rebuild: `npm install && npm run build`, then copy `dist/` to `docs/`.
